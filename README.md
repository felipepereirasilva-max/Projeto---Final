# Clínica Fácil 

Sistema de gerenciamento de clínicas desenvolvido para a disciplina de Programação Orientada a Objetos (POO).

## Sobre o projeto

O Clínica Fácil tem como objetivo facilitar a organização de clínicas, permitindo o gerenciamento de pacientes, médicos, recepcionistas, especialidades, consultas e atendimentos.

## Funcionalidades

- Cadastro de pacientes, médicos e recepcionistas.
- Cadastro de clínicas e especialidades.
- Agendamento e consulta de consultas médicas.
- Registro de atendimentos, diagnósticos e prescrições.

## Instruções de Funcionalidades

O sistema Clínica Fácil tem como objetivo organizar as informações e facilitar o gerenciamento de uma clínica.

- **Cadastro de pessoas:** registrar nome, CPF, telefone, e-mail e endereço.
- **Pacientes:** cadastrar e consultar os dados dos pacientes.
- **Médicos:** registrar os dados dos médicos e suas especialidades.
- **Recepcionistas:** cadastrar os funcionários responsáveis pela recepção.
- **Clínica:** registrar informações como nome, CNPJ, endereço e telefone.
- **Especialidades:** cadastrar e consultar as especialidades médicas.
- **Consultas:** registrar data, horário, paciente, médico e status da consulta.
- **Atendimentos:** registrar informações como data, diagnóstico, prescrições e observações.

Essas funcionalidades ajudam a manter os dados organizados e facilitam o acompanhamento das consultas e dos atendimentos.
